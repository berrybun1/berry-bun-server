# 🍓 Berry Bun - Adopt Me Server Website

A cute and aesthetic website for your Adopt Me grinding server with status display and easy join functionality.

## Features ✨

- **Cute Cutecore Design** - Pink, pastel aesthetic with animated elements
- **Server Status Display** - Shows if server is open/closed
- **Player Counter** - Displays current player count
- **Easy Join Button** - Direct link to your private server
- **Copy Code Function** - Easy server code sharing
- **Responsive Design** - Works on mobile and desktop
- **Smooth Animations** - Floating elements, smooth scrolling, entrance animations

## Files

- `index.html` - Main website structure
- `style.css` - Complete styling with animations
- `script.js` - Interactive functionality

## How to Deploy

### Option 1: GitHub Pages (Free & Easy)
1. Go to your repository settings
2. Scroll to "GitHub Pages"
3. Select `main` branch as source
4. Your site will be live at `https://berrybun1.github.io/berry-bun-server`

### Option 2: Netlify (Free & Fast)
1. Connect your GitHub repo to Netlify
2. Set build command to empty
3. Set publish directory to `/`
4. Deploy!

### Option 3: Vercel (Free & Fast)
1. Import your GitHub repo to Vercel
2. Keep all settings as default
3. Deploy!

## Customization

### Change Server Link
Edit the Roblox server link in `index.html`:
```html
href="https://www.roblox.com/share?code=YOUR_CODE_HERE&type=Server"
```

### Change Colors
Edit the gradient colors in `style.css`:
- Main pink: `#ff69b4`, `#ff1493`
- Accent pink: `#ffb3d9`
- Text color: `#6b4e71`

### Update Status
The status currently shows random player counts. To integrate real Roblox API data, you'll need a backend service (Node.js, Python, etc.) to query the Roblox API securely.
